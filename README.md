# Shivdurg — Sahyadri Fort Heritage Website

Complete responsive website built with HTML, CSS, and JavaScript featuring authentic Wikimedia Commons photographs of Maharashtra's historic forts and your custom Fort Emblem Map Pin Icon.

## Folder Structure
- `index.html` — Main website entry point
- `pages/` — Separate folder for all given pages:
  - `pages/home.html` — Discover the Majestic Forts of Maharashtra (Hero, Featured Forts, Region Belts, Fort Types & Safety)
  - `pages/fort-map.html` — Interactive Forts of Maharashtra Atlas & Map with Custom Fort Pin Markers & GPX Export
  - `pages/fort-detail.html` — Raigad Fort (किल्ले रायगड) & Switchable 12-Fort Architectural Dossier, Timeline & Elevation Profile
  - `pages/explore-forts.html` — Complete filterable directory of Maharashtra forts
  - `pages/trekking-guides.html` — Multi-fort Sahyadri trek circuits & seasonal guides
  - `pages/history.html` — Ajnapatra & Maratha Military Landscapes history
  - `pages/gallery.html` — 100% real archival photographic gallery from Wikimedia Commons
  - `pages/about-contact.html` — Conservation Guard & Contact dispatch
- `forts-data/` — Single folder containing all fort data (`all-forts.json`, `all-forts.js`, and individual `<fort-id>.json` files for `raigad`, `rajgad`, `sindhudurg`, `pratapgad`, `lohagad`, `visapur`, `suvarnadurg`, `torna`, `sinhagad`, `shivneri`, `vijaydurg`, `panhala`, `janjira`, `harishchandragad`, `salher`, `daulatabad`)
- `css/styles.css` — Mobile-first responsive stylesheet
- `js/app.js` — Interactive map, filters, audio guide, GPX generator, and modal controller
- `assets/icons/fort-pin.png` — Custom golden fort-and-swords map pin icon
